# excel-sales-dashboard
Interactive Excel sales dashboard for analyzing revenue, profit, and regional performance

## Project Overview

This project is an interactive Excel sales dashboard designed to analyze sales performance and present key business insights through KPIs, charts, and interactive filters.

## Workbook Structure

### Sales Data
Contains the main sales dataset used for the analysis and dashboard.

### Price
Contains product pricing information used in the sales analysis.

### KPI
Contains the calculations used to generate the key performance indicators.

### Dashboard
The main interactive dashboard containing the final KPIs, charts, and slicers for exploring the sales data.

## Dashboard Features

- Final sales KPIs
- Interactive charts
- Slicers for filtering and exploring the data
- Sales performance analysis
- Data-driven visualizations

## Tools Used

- Microsoft Excel
- Excel formulas
- Pivot Tables
- Charts
- Slicers
- KPI calculations
- Data visualization

## How to Use

1. Download the Excel dashboard file.
2. Open it using Microsoft Excel.
3. Go to the **Dashboard** sheet.
4. Use the slicers to filter the data.
5. Explore the KPIs and charts to analyze sales performance.

## Project Purpose

This project demonstrates my ability to organize sales data, perform analysis, create KPIs, and build an interactive dashboard using Microsoft Excel.
